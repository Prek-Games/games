# Preschool Games

Two classroom games for preschoolers, made to run in any web browser:

- **Animal Picture Match** (`memory-game.html`): a memory game with cartoon animals, for one player or Red Team vs. Blue Team.
- **Letter Review** (`letter-review.html`): big, easy-to-read letter flash cards. The teacher chooses letters or letter sets first.
- **Letter Picture Cards** (`letter-picture-cards.html`): the same letter game using the classroom's Fundations picture cards.

`index.html` is the home page that links to both.

Everything is plain HTML in single files with nothing to install. The drawings and the letter font are built into the files, so the games also work offline once they have loaded.
